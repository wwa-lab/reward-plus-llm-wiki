## 如何追加一行

1. 检索"接口名"与"别名"（对端系统可能对同一接口有不同叫法），确认尚未登记。
2. 新 ID = 当前最大 ID + 1，例如 `IF-0001`。
3. 方向：入站 / 出站 / 双向。类型：文件 / 数据队列(DTAQ) / 消息队列(MQ) / API / 数据库直连 / 远程程序调用 / 屏幕终端 / 打印与假脱机 / 共享文件 / 未知。
4. 对端系统填 `SYS-####`；生产方与消费方填 `PROG-####`（已知时）。
5. 证据引用：接口规格文档位置，或生产/消费该接口的程序证据。
6. **更新文件头部的"当前最大 ID"**。
7. 用 [interface-template](../../templates/interface-template.md) 建知识页，**同一次提交完成**。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 注意

* 接口的字段映射要指回 `DATA-####`，写在知识页里，不堆在登记表。
* 传输机制与格式（定长 / CSV / XML / JSON）记在知识页，本表只记方向与类型。
* 一个接口可能被多个程序消费，允许多个 `PROG-` 出现在"消费方"列。
* **对端系统只写 `SYS-####`**；系统本身的职责、协议、负责人登记在 [systems.md](systems.md)。
* **内部程序之间的调用不建 `IF-`**，记在 `PROG-` 页的 callers / callees。

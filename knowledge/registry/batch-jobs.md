## 如何追加一行

1. 确认有调度清单、CL 程序或运行日志作为证据。
2. 新 ID = 当前最大 ID + 1，例如 `JOB-0001`。
3. "前置依赖"只填**有证据**的依赖（作业、文件到达、时间窗口）；推断的依赖在知识页里单列一栏。
4. 涉及程序填 `PROG-####`。
5. **更新文件头部的"当前最大 ID"**。
6. 首份作业知识页建立时，同步补建 `templates/batch-job-template.md`；在此之前暂用 [program-template](../../templates/program-template.md) 的程序段落 + 本表字段。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 注意

* **执行顺序与依赖必须有证据。** 顺序错误在迁移后会造成严重事故。
* 时间窗口与数据量前提（例如"日切后运行"）要记在知识页，这是行为的重要前提。
* 失败处理（重跑、断点续跑、人工干预）是迁移时最容易漏的部分，务必记录。

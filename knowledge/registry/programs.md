## 如何追加一行

1. 检索"规范名"与"别名"，确认程序尚未登记（注意不同库中的同名程序）。
2. 新 ID = 当前最大 ID + 1，例如 `PROG-0001`。
3. 类型：在线 / 批量 / 子过程 / 服务程序 / 未知。
4. 证据引用写**代码扫描输出**的位置：`raw/PRJ-####/code-scan-results/<文件>，行 N`。
5. **更新文件头部的"当前最大 ID"**。
6. 用 [program-template](../../templates/program-template.md) 建知识页，**同一次提交完成**。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 注意

* **没有业务映射的程序照常登记**，状态标 `NEEDS_REVIEW`，并写入"未匹配程序"清单。
* 多批扫描结果说法不一致 → 标 `CONFLICTED`，两批都引用并注明扫描日期。
* 调用关系是事实，"属于某功能"是推断，两者不要混填在一列里。

## 如何追加一行

1. 原始测试定义放 `raw/PRJ-####/test-cases/`，执行结果放 `raw/PRJ-####/test-results/`；本表登记的是**规范化后可复用**的规格。
2. 新 ID = 当前最大 ID + 1，例如 `TEST-0001`。
3. "验证对象"填 `FUNC-####` / `RULE-####` / `PROG-####`；环境：遗留 / 新系统 / 两者。
4. "执行结果引用"**只有在 `raw/PRJ-####/test-results/` 里确有原始输出时才填**。没有引用就不能写"通过"。
5. **更新文件头部的"当前最大 ID"**。
6. 用 [test-case-template](../../templates/test-case-template.md) 建规格页，放 `tests/validation/`，**同一次提交完成**。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 注意

* **测试通过 ≠ 行为正确。** 通过只说明"该输入下是该输出"，不代表业务需求被正确实现。
* 用例数据一律合成或掩码，**禁止真实卡号、真实客户信息**。
* 失败或意外结果记为发现，可能推翻已确认知识；上报，不要改期望值让它变绿。
* 未关联到已知功能的测试结果先在 `analysis/reports/` 记录，等功能页建立后回填 ID。

## 如何追加一行

1. 从 `raw/PRJ-####/fe-menus/` 的导出中确认该条目确实存在（这是 `EVIDENCE_FOUND` 的依据）。
2. 新 ID = 当前最大 ID + 1，例如 `MENU-0001`。
3. "关联功能 / 关联程序"**只在有证据时填**：调用链、程序名与标签的对应、屏幕定义、SME 说明。
4. **映射置信度单独一列**：high / medium / low / unknown。菜单结构本身可以有证据，映射到功能仍可能是推断——两者分开记。
5. 无证据的映射 → 状态 `INFERRED` 或 `NEEDS_REVIEW`，备注写明"需要什么证据才能确定"。
6. **更新文件头部的"当前最大 ID"**。
7. 用 [menu-entry-template](../../templates/menu-entry-template.md) 建知识页，**同一次提交完成**。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 重要：不要假设一对一

一个菜单项可能触发一串程序；一个程序可能被多个菜单调用；有的菜单项只是导航容器；有的程序没有菜单入口。
**允许空缺，不允许硬填。** 未匹配项汇总到 `analysis/reports/` 的"未匹配菜单项"清单。

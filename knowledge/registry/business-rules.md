## 如何追加一行

1. 确认这是**一条**可独立识别的规则（一个条件 + 一个结果）。能用"并且"拆成两个独立判断的，拆成两条。
2. 检索"规范名"与"别名"，确认尚未登记。
3. 新 ID = 当前最大 ID + 1，例如 `RULE-0001`。
4. 分类待实际内容积累后再固化（如 资格 / 计算 / 校验 / 生命周期），初期可写"未分类"。
5. 证据引用至少 1 处直接来源（代码位置或文档原文）。**纯推断只能标 `INFERRED`。**
6. **更新文件头部的"当前最大 ID"**。
7. 用 [business-rule-template](../../templates/business-rule-template.md) 建知识页，**同一次提交完成**。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 已实现 vs 期望

文档说 A、代码做 B 时**不要选边**：

* 两处来源都写进"证据引用"；
* 状态标 `CONFLICTED`；
* 备注注明差异性质，知识页的"冲突"段落写明谁能裁决。

这条差异本身就是迁移要处理的重要问题，不要抹掉。

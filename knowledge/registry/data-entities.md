## 如何追加一行

1. 检索"业务名""物理名""别名"，确认尚未登记。
2. 新 ID = 当前最大 ID + 1，例如 `DATA-0001`。
3. 类型：物理文件 / 逻辑文件 / 表 / 视图 / 控制文件 / 参数文件 / 未知。
4. **不编造字段定义与类型。** 没有定义来源就写"未知"。
5. 证据引用：扫描输出或设计文档的位置。
6. **更新文件头部的"当前最大 ID"**。
7. 用 [data-entity-template](../../templates/data-entity-template.md) 建知识页，**同一次提交完成**。

## 状态取值

`EVIDENCE_FOUND` · `INFERRED` · `NEEDS_REVIEW` · `SME_CONFIRMED`（需记录确认人与日期）· `CONFLICTED` · `SUPERSEDED`

## 注意

* 物理结构与业务概念要分开记：一个文件可能承载多个业务概念，反之亦然。差异写进备注。
* 同一数据对象的多个叫法（程序名、报表名、业务名）全部记入"别名"。
* 字段的业务含义如果是个**业务术语**，去 `terms.md` 登记 `TERM-####`，不要在这里自己定义。
* 如果这个对象是**控制文件 / 参数文件**：本页只写物理结构，**参数语义与"改它影响谁"写 `CFG-####`**（见 [control-params.md](control-params.md)）。

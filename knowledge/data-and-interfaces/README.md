# knowledge/data-and-interfaces/ — 数据与接口

物理数据结构与对外契约放在同一个目录，但用**不同 ID 前缀**区分：

| 类型 | ID 前缀 | 模板 |
|---|---|---|
| 数据实体（文件、表、视图） | `DATA-####` | [templates/data-entity-template.md](../../templates/data-entity-template.md) |
| 接口 / API / 外部交换 | `IF-####` | [templates/interface-template.md](../../templates/interface-template.md) |
| 对端系统（接口的另一头） | `SYS-####` | [templates/system-template.md](../../templates/system-template.md)，知识页在 [`../external-systems/`](../external-systems/) |

> **控制文件 / 参数文件**：物理结构在本目录按 `DATA-####` 记；**参数语义与"改它影响谁"在
> [`../configuration/`](../configuration/)（`CFG-####`）**。两处互相指认，不重复内容。

## 数据实体（`DATA-####`）

讲清：业务含义、物理结构（文件名/库/类型）、键字段、字段说明、关系、读写使用方、来源与证据。

**字段级引用**：`DATA-0007.EXPIRY_DATE`。

**完整数据字典不进本目录。** 全部字段定义作为原始输入放 `raw/PRJ-####/data-dictionary/`（CSV，登记 `SRC-####`），
本页通过 `dictionary_ref` 指向它，**只写驱动行为的字段**。理由见 [`raw/_types/data-dictionary.md`](../../raw/_types/data-dictionary.md)。

要求：

* **物理结构与业务概念要分清。** 一个文件可能承载多个业务概念，一个业务概念也可能散在多个文件。
* **不编造字段定义和类型。** 没有定义来源就写"未知"。
* 只写"值得关注的字段"，不必罗列所有列——重点是驱动行为的字段。
* 记录数据质量问题：默认值、空值处理、编码、日期格式、被复用/废弃的字段。

## 接口（`IF-####`）

讲清：接口类型、对端系统、生产方与消费方、触发方式、输入/输出结构、数据转换、错误处理、依赖、相关功能与程序、证据。

**先判断该不该建 `IF-`（三条边界规则）：**

| 情形 | 走哪 | 说明 |
|---|---|---|
| 内部程序之间的调用 | `PROG-####` 页的 callers / callees | **不建 `IF-`** |
| 用户面对的菜单与屏幕 | `MENU-####`（`menus-and-navigation/`） | **不建 `IF-`**；屏幕被外部程序自动化调用时才建 |
| 批量文件交换 | 物理结构 `DATA-####` + 交换契约 `IF-####` | 本页引用 `DATA-`，不复制字段定义 |
| 与外部系统交换 | `IF-####` + 对端 `SYS-####` | 对端系统单独登记 |

要求：

* 区分**入站**与**出站**。
* 记录传输机制与格式。类型取值：文件 / 数据队列(DTAQ) / 消息队列(MQ) / API / 数据库直连 /
  远程程序调用 / 屏幕终端 / 打印与假脱机 / 共享文件 / 未知。
* **对端系统写 `SYS-####`**，不写系统名；系统本身的职责与协议在 `../external-systems/`。
* 字段映射表要指明对应的 `DATA-####`。
* 错误处理要写清：校验失败、拒绝、重试、重复处理、错误通知分别怎么做。

## 不放什么

* 完整数据字典（引用扫描输出即可）
* 生产数据样例
* 未确认的字段猜测（→ 标 `INFERRED` 或写"未知"）

## 关系维护

* 数据实体页列出读写它的 `PROG-####` 和涉及的 `FUNC-####`。
* 接口页列出生产/消费它的 `PROG-####`、下游 `JOB-####`，以及**对端 `SYS-####`**。
* 对端系统页（`../external-systems/`）列出关联的 `IF-####`。
* 双向维护：程序页也要列出它读写的 `DATA-####` 与使用的 `IF-####`。
* **列出涉及项目（`PRJ-####`）**：这张表 / 这个接口是被哪几次交付改过。
  字段被反复加过（历史遗留字段、已废弃但仍存在的列）往往就是多次交付叠加的结果。

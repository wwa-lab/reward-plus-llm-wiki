# 类型：前端菜单与导航材料

存放前端菜单导出、导航清单、界面层级材料。用途是**把用户看到的入口，连到后端的功能和程序**。

## 放什么

* 菜单导出（Excel / CSV / JSON）
* 导航树、菜单层级清单
* 界面截图（大图放同 project 的 `diagrams-and-images/`，此处可放清单）
* 菜单与程序对应关系的**原始**材料（如有）

## 不放什么

* 菜单到功能的**臆测**映射（放 `analysis/reports/`）
* 未经批准的内部界面导出
* 含真实客户信息的截图

## 使用方式

1. 存进来时登记 `SRC-####`。
2. 梳理菜单层级与导航项，登记 `MENU-####`（见 `knowledge/registry/menu-entries.md`）。
3. 映射到功能 / 程序时**必须有证据**：调用链、程序名与菜单标签的对应、或 SME 说明。
4. 没有证据 → 标 `INFERRED` 或 `NEEDS_REVIEW`，并写明需要什么证据才能确定。
5. 输出"未匹配菜单项"清单到 `analysis/reports/`。

## 重要提醒

**菜单项与程序不是一对一关系。**

* 一个菜单项可能触发一串程序。
* 一个程序可能被多个菜单项调用。
* 有的菜单项是纯导航，背后没有业务处理。
* 有的程序没有任何菜单入口（只被批量作业或接口调用）。

所以菜单映射表**允许空缺**，不允许硬填。映射置信度单独记一列（`mapping_confidence`）。
